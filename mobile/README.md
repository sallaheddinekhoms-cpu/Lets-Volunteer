# تطبيق الموبايل « لنتطوع » (Lets-Volunteer Mobile App) 📱🇩🇿

تطبيق موبايل هجين عالي الأداء مبني بأحدث إصدارات **React Native (Expo v58) + TypeScript**، يضم كافة مميزات وخدمات منصة «لنتطوع» الوطنية، ومتصل بالواجهة الخلفية (Django REST API).

---

## 🌟 الميزات المضمنة في تطبيق الموبايل:

1. **الرئيسية وشريط العاجل (Home & Alerts):**
   - شريط أحمر للنداءات العاجلة وحالات التدخل الإنساني والإسعافي الطارئ.
   - بوابات الوصول السريع لجميع خدمات المنصة.
   - مؤشرات إحصائية حية لساعات التطوع، الفرص، والولايات.
   - موجز لأحدث المبادرات التطوعية.

2. **دليل الفرص ونظام GPS الميداني (Opportunities & Live GPS):**
   - محرك بحث متقدم بالكلمات المفتاحية والمجالات.
   - شريط تصفية أفقي لكافة ولايات الوطن (58 ولاية).
   - التبديل السلس بين **عرض القائمة (Cards View)** و **خريطة التموضع الجغرافي GPS**.
   - بطاقة تفاصيل الفرصة والتسجيل الفوري المباشر بضغطة زر.

3. **متجر التطوع والتكافل المجتمعي (Solidarity Store):**
   - تصفح المستلزمات الطبية، العكازات، الكراسي المتحركة، والأجهزة الصحية المجانية.
   - التبديل بين **الإعارة المؤقتة المجانية** و **التبرع الدائم النهائي**.
   - الاتصال المباشر بالمتبرع عبر الهاتف أو فتح محادثة **WhatsApp** فورياً.
   - نموذج إدراج غرض جديد في المتجر مباشرة من الهاتف.

4. **أكاديمية المتطوع الجزائري وفضاء التكوين (Trainings):**
   - ورشات عمل ودورات تأهيلية معتمدة (إسعافات أولية، قيادة فرق، صناعة محتوى).
   - توضيح صيغة الدورة (حضوري ميداني / عن بعد عبر الإنترنت)، الساعات، والمدرب.
   - التسجيل الفوري المجاني بنقرة واحدة.

5. **البطاقة الوطنية الرقمية للمتطوع (National Digital Volunteer ID):**
   - تصميم سيادي رسمي يحمل ترويسة الجمهورية الجزائرية.
   - رقم قيد وطني موحد `DZ-VOL-2026-XXXX`.
   - إبراز **فصيلة الدم (Blood Group)** لحالات الإسعاف والطوارئ في الميدان.
   - رمز استجابة سريعة **QR Code** للفحص والتحقق الميداني من قِبل السلطات المعنية.
   - عداد الساعات المعتمدة في السجل الوطني.

6. **نظام الشكاوى والدعم الميداني (Support & Grievances):**
   - نموذج رسمي لفتح تذاكر الشكاوى والمقترحات والرد الإداري خلال 24 ساعة.
   - عرض ميثاق المتطوع والامتثال للقانون 12-06 وقانون حماية المعطيات الشخصية 18-07.

## 🚀 كيفية تشغيل واختبار التطبيق:

### 1. التشغيل والمعاينة على هاتفك الشخصي مباشرة (عبر Expo Go):
1. افتح موجه الأوامر وانتقل لمجلد الموبايل:
   ```bash
   cd mobile
   npm start
   ```
2. ثبّت تطبيق **Expo Go** مجاناً من متجر Google Play (للأندرويد) أو App Store (للآيفون).
3. امسح رمز الاستجابة السريعة (QR Code) الظاهر في شاشة الـ Terminal بكاميرا الهاتف أو داخل Expo Go.
4. سيعمل التطبيق فوراً على هاتفك بكامل سلاسته وتفاعليته!

### 2. التشغيل على محاكي الأندرويد (Android Emulator):
```bash
cd mobile
npm run android
```

### 3. استخراج ملف التثبيت المباشر (APK) للأندرويد:
تم إعداد ملف [`eas.json`](eas.json) لبناء ملف APK قابل للتثبيت المباشر على أي هاتف أندرويد بدون متجر:
```bash
cd mobile
npx eas-cli build -p android --profile preview
```
*(ملاحظة: يتطلب حساباً مجانياً على Expo.dev، وسيقوم ببناء ملف الـ APK في السحابة وتوفير رابط تحميل مباشر ومسح QR لتثبيته فوراً على الهواتف).*

### 3. المعاينة السريعة على المتصفح (Web):
```bash
cd mobile
npm run web
```
