# تطبيق الموبايل « لنتطوع » بفلاتر (Flutter Mobile App) 📱🇩🇿

تطبيق هاتف محمول متكامل ومكتوب بلغة **Dart & Flutter (v3.44.0)** لمنصة «لنتطوع» الوطنية للعمل التطوعي في الجزائر.

---

## 🌟 الميزات والأقسام المنجزة:

1. **الرئيسية وشريط العاجل (`home_screen.dart`):**
   - ترويسة سيادية رسمية بالهوية الوطنية الجزائرية.
   - شريط العاجل الأحمر للنداءات الميدانية وحالات الطوارئ.
   - بوابات الوصول السريع لكافة أقسام المنصة.
   - مؤشرات إحصائية وطنية حية (الساعات المعتمدة، الفرص النشطة، تغطية الولايات).
   - عرض أبرز المبادرات مع إمكانية الانضمام الفوري.

2. **دليل وخريطة الفرص التطوعية (`opportunities_screen.dart`):**
   - محرك بحث متقدم بالكلمات المفتاحية والمجالات.
   - فلترة أفقية سريعة حسب الولايات الـ 58 (`AppConstants.wilayas`).
   - نمط عرض مزدوج: **قائمة البطاقات** و **خريطة التموضع الميداني GPS**.
   - تسجيل فوري مع تفاصيل نقطة الاتصال والهاتف المعتمد.

3. **متجر التطوع والتكافل الصحي (`solidarity_store_screen.dart`):**
   - تبويبات منفصلة: **إعارة مجانية مؤقتة** (كراسي متحركة، عكازات، أجهزة تنفس) و **تبرع دائم نهائي**.
   - زر الاتصال الهاتفي المباشر بالمتبرع (`tel:...`).
   - زر محادثة **WhatsApp** الفورية المباشرة.
   - نافذة إيداع غرض جديد في المتجر.

4. **أكاديمية المتطوع وفضاء التكوين (`trainings_screen.dart`):**
   - دورات تأهيلية معتمدة (إسعافات أولية، إدارة أزمات، صناعة محتوى تنموي).
   - تصنيف نمط الدورة: حضوري ميداني / عن بعد عبر الإنترنت.
   - تسجيل مجاني بضغطة زر مع احتساب الساعات المعتمدة.

5. **البطاقة الوطنية الرقمية ونظام الشكاوى (`profile_screen.dart`):**
   - **البطاقة البيومترية الرسمية للمتطوع**: رقم القيد الموحد `DZ-VOL-2026-XXXX`، فصيلة الدم، رمز الاستجابة السريعة المباشر (QR Code)، وشريط الساعات المعتمدة.
   - **الضمانات والمطابقة القانونية**: الامتثال لمقتضيات القانون رقم **12-06** وقانون حماية البيانات الشخصية رقم **18-07**.
   - **نظام الشكاوى والدعم**: استمارة فتح تذكرة رسمية موجهة للجنة الرقابة والمطابقة.

## 🚀 كيفية تشغيل واختبار تطبيق Flutter:

### 1. تشغيل التطبيق على متصفح الويب (Chrome / Edge):
```bash
cd mobile_flutter
flutter run -d chrome
```

### 2. تشغيل التطبيق على الهاتف الموصول أو محاكي الأندرويد:
```bash
cd mobile_flutter
flutter run
```

### 3. استخراج ملف التثبيت المباشر (APK) للأندرويد:
```bash
cd mobile_flutter
flutter build apk --split-per-abi
# أو استخراج ملف APK شامل:
flutter build apk --release
```
الملف الناتج سيكون متاحاً في:
`mobile_flutter/build/app/outputs/flutter-apk/app-release.apk`
